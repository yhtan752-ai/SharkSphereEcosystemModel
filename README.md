# The Ocean Research Mission | SharkSphere

This repo contains a web-based SPA experience developed for OceanX's SharkSphere track!
The game is built using a simple HTML/CSS/JS stack, with a focus on scientific accuracy first.

<hr>

## To Run:
Everything is locally hosted, so no backend is required to run the game. Just open `index.html` in a web browser.

## Requirements:
- A reasonably modern web browser (Chrome, Firefox, Edge)
- Designed exclusively for fixed 1280x720 px screen bifold/trifold
